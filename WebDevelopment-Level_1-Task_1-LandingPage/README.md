# 🌿 PlantPal - Smart Plant Care Landing Page (OIBSIP Task 1)

> A modern, highly interactive, and visually stunning Landing Page web application built for **PlantPal** — an AI-powered smart plant care ecosystem. Developed for the **Oasis Infobyte Web Development Internship (OIBSIP - Level 1 Task 1)**.

---

## 🌟 Features & Interactive Highlights

- **📱 Interactive Smartphone Mockup (Hero Section)**
  - **💧 Water Button**: Simulates real-time soil hydration filling the moisture progress bar to 100%.
  - **📸 AI Scanner Simulation**: Click to activate a glowing laser scan beam that cycles through plant identification cards and care metrics.
  - **Clickable Floating Badges**: Interactive badges triggering popups and care status feedback.

- **⚡ Interactive AI Care Playground (`#demo`)**
  - **Plant Species Switcher**: Interactively switch between **Monstera**, **Calathea**, **Fiddle-Leaf**, **Snake Plant**, and **Peace Lily** models.
  - **Live Diagnostics**: Real-time moisture bars, sunlight meters, and dynamic AI care tips.
  - **Interactive Action Buttons**: Log watering events and set automated care reminders on the fly.

- **🗂️ Category Filter Tabs (`#features`)**
  - Filter features smoothly by category: **All Capabilities**, **AI & Vision**, **Smart Care**, and **Health & Disease**.

- **✨ Smart Onboarding Modal**
  - Clickable *"Get Started"* and *"Try PlantPal Free"* CTA buttons open a frosted glass modal form for seamless user onboarding.

- **❓ Frequently Asked Questions (`#faq`)**
  - Clean, accessible accordion interface with smooth toggle animations.

- **🔔 Toast Notification System**
  - Floating toast popups for instant visual feedback across all user interactions.

- **🌱 Plant Room Micro-Animation (`#about`)**
  - Click the indoor plant illustration to watch a plant growth bounce animation.

- **📍 Active Scrollspy Navigation**
  - Header links dynamically highlight as you scroll down the page.

## 🚀 How to Run Locally

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/upasanaX/OIBSIP.git
   ```

2. **Navigate to Task Directory:**
   ```bash
   cd OIBSIP/WebDevelopment-Level_1-Task_1-LandingPage
   ```

3. **Serve Locally:**
   - Using Python:
     ```bash
     python -m http.server 8085
     ```
   - Or open `index.html` directly in any modern web browser.

4. **Access in Browser:**
   Open `http://localhost:8085` in your browser.
