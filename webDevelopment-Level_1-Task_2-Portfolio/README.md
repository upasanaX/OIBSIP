## ✨ Features & Highlights

- 🎨 **Modern Glassmorphism UI:** Built with a sleek dark aesthetic, vibrant cyan/indigo accent gradients, and floating background blobs.
- 📸 **Personal Profile Picture Integration:** Integrates real profile portrait (`assets/upasana-profile.jpg`) with floating developer badge and glowing radial backdrops.
- 📱 **Fully Responsive Layout:** Optimized for desktop, tablet, and mobile viewports with an intuitive mobile hamburger navigation menu.
- 📜 **ATS-Optimized Resume:** Includes an interactive web resume (`resume.html`) and direct downloadable PDF format (`resume.pdf` & `assets/resume.pdf`).
- 🚀 **Interactive Portfolio Sections:**
  - **Hero Section:** Dynamic typing text animation and quick action buttons.
  - **About Me:** Academic background at RCCIIT Kolkata, engineering philosophy, and career goals.
  - **Technical Skills:** Categorized breakdown covering Programming Languages, Frontend Engineering, Backend & Systems, AI/ML & Computer Vision, Databases & ORMs, and Cloud/DevOps.
  - **Featured Projects:** Showcase of major solo projects & contributions with interactive category filtering (*All*, *⭐ Solo Projects*, *AI & Computer Vision*, *Full Stack*, *Frontend & React*):
    - 🎯 **TrackOptic AI:** Real-time deep learning multi-object tracking suite (YOLOv8s + SORT + Kalman Filters over 30+ FPS WebSockets).
    - 🌐 **GlobePay:** Global 1-tap scan & pay fintech platform with instant zero-markup FX conversion and multi-currency wallets.
    - 🌾 **KrishiKavach (कृषिकवच):** Smart India Hackathon national agro-meteorological downscaled 2.5 km grid & direct marketplace.
    - 🌍 **TripMate Travel Companion:** AI-powered travel discovery and itinerary planner (Next.js 16, PostgreSQL, Gemini AI & Groq).
    - 🤖 **Coursemate AI & LinguoFlow PRO:** NLP TF-IDF cosine similarity chatbot & 24+ language neural translator with speech synthesis.
    - 💼 **OIBSIP Suite:** Solo web development internship projects repository.
  - **Work Experience & Internships:** Detailed timeline covering CodeAlpha (AI Intern) and Oasis Infobyte (Web Dev Intern).
  - **Education & Highlights:** Academic degree at RCCIIT Kolkata and key achievements.
  - **Contact Form:** Interactive contact form with input validation and toast notifications.

## 🚀 Local Setup & Preview

1. **Clone the repository:**
   ```bash
   git clone https://github.com/upasanaX/OIBSIP.git
   cd OIBSIP/webDevelopment-Level_1-Task_2-Portfolio
   ```

2. **Run locally using any static HTTP server:**
   ```bash
   npx http-server -p 8080
   ```

3. Open **`http://localhost:8080`** in your web browser.
