# 💼 Web Development Level 1 - Task 2: Personal Portfolio & Resume

> A responsive, interactive Personal Portfolio Website and ATS Resume built using **HTML5**, **CSS3**, and **Vanilla JavaScript**. Developed for the Oasis Infobyte Web Development Internship (OIBSIP).

## 📌 Overview
This repository folder contains the complete codebase for Task 2:
- `index.html` - Interactive Portfolio Homepage
- `resume.html` - Professional ATS-friendly Resume
- `style.css` - Custom styling, dark aesthetic, responsive design
- `script.js` - Dynamic interactions and animations
- `assets/` - Project media and resume documents

## 🛠️ Usage
Open `index.html` in any web browser to view the Portfolio website.
