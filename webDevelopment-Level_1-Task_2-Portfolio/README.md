# 💻 Upasana Roy | Personal Portfolio & ATS Resume Web Application

> **Oasis Infobyte Web Development Internship (OIBSIP) — Level 1, Task 2**
>
> A modern, responsive, and feature-rich Personal Portfolio Website & ATS-Friendly Resume built with **HTML5**, **CSS3 (Glassmorphism & Custom Styling)**, and **Modular Vanilla JavaScript**.

---

## ✨ Features & Highlights

- 🎨 **Modern Glassmorphism UI:** Built with a sleek dark aesthetic, vibrant accent gradients, and floating background blobs.
- 📱 **Fully Responsive Layout:** Optimized for desktop, tablet, and mobile viewports with an intuitive mobile hamburger navigation menu.
- 📜 **ATS-Friendly Resume:** Includes an interactive web resume (`resume.html`) and direct downloadable PDF format (`assets/resume.pdf`).
- 🚀 **Interactive Portfolio Sections:**
  - **Hero Section:** Dynamic typing text animation and quick action buttons.
  - **About Me:** Academic background at RCCIIT Kolkata, core interests, and career goals.
  - **Technical Skills:** Categorized breakdown covering Programming Languages, Frontend, Backend, Database, Tools, and Core CS Concepts.
  - **Featured Projects:** Showcase of 5 major projects (*Nayak Legal Tech*, *GlobePay*, *TripMate*, *Bharat ID*, and *Health Insights*) with live preview modals and repository links.
  - **Education & Highlights:** Structured timeline detailing degree and achievements.
  - **Contact Form:** Interactive contact form with input validation and toast notifications.

## 🛠️ Tech Stack & Tools

- **Core:** HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Styling:** Custom CSS Flexbox/Grid, Glassmorphism, CSS Variables, Keyframe Animations
- **Typography & Icons:** Google Fonts (Poppins), FontAwesome 6.5
- **Tooling & Local Dev:** Node.js, `http-server`, Git, GitHub

---

## 🚀 Local Setup & Preview

1. **Clone the repository:**
   ```bash
   git clone https://github.com/upasanaX/OIBSIP.git
   cd OIBSIP/webDevelopment-Level_1-Task_2-Portfolio
   ```

2. **Run locally using any static HTTP server:**
   ```bash
   npx http-server -p 8080
   ```

3. Open **`http://localhost:8080`** in your web browser.
