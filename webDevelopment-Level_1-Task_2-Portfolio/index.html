TrackOptic AI — Real-Time Computer Vision Suite

TrackOptic AI is an end-to-end computer vision platform engineered during the CodeAlpha AI Internship, designed for high-precision multi-object tracking and telemetry analysis.

Core Technical Highlights:

  • YOLOv8s Spatial Detection: Fast and accurate bounding box localization across custom and COCO classes.
  • Kalman Filter Motion Estimation: Continuous 24-point centroid trajectory polylines predicting position through temporary occlusions.
  • Class-Consistent SORT Tracking: Enforces zero track switching across different object classes ($IoU = 0.0$ penalty).
  • Virtual Laser Tripwire: Interactive bidirectional crossing counter (`⬆️ IN` / `⬇️ OUT` / `Total`) with audio feedback alerts.
  • Multi-Spectrum Optical Filters: GPU-accelerated client-side canvas shaders simulating Optical RGB, FLIR Thermal IR, and Tactical Night Vision (NVG).
  • High-Throughput WebSocket Pipeline: Full-duplex `ws://` stream delivering 30+ FPS video with sub-50ms inference feedback.

Tech Stack:

Python 3.11, FastAPI, YOLOv8s, OpenCV, PyTorch, WebSockets, React 18, TypeScript, Tailwind CSS, SQLite.

GlobePay — Global 1-Tap Payment Platform

GlobePay simplifies cross-border commerce by allowing users to scan any foreign merchant QR code (Tokyo, Paris, London, Dubai) and pay with automatic currency exchange in 1 tap at 0% foreign markup.

Key Technical Highlights:

  • Universal 1-Tap QR Scanner: Interactive camera viewfinder auto-detects merchant currency (JPY, EUR, GBP, AED) and debits home balance seamlessly.
  • Real-Time FX Engine: Mid-market currency exchange rates across USD, EUR, GBP, JPY, INR, and AED with zero hidden spreads.
  • Virtual Card Controls: Instant virtual debit card issuance, 1-click Freeze / Unfreeze toggle, and daily spending limit caps.
  • Atomic Ledger & Security: Knex query builder with SQLite persistent storage, short-lived JWT access tokens (15m), and bcrypt password hashing.

Tech Stack:

React 18, TypeScript, Tailwind CSS, Node.js, Express REST API, SQLite, Knex, JWT Auth.

KrishiKavach (कृषिकवच) — Smart India Hackathon

Developed for Smart India Hackathon (SIH 2026) by Team TechBrats, KrishiKavach is a national digital agriculture and disaster mitigation platform protecting smallholder farmers against localized convective cloudbursts and middleman exploitation.

Key Technical Highlights:

  • Hyperlocal Downscaling: Downscales broad 25–50 km meteorological forecasts into localized 2.5 km micro-grids using spatial XGBoost residual modeling.
  • Proactive 6–12h Warnings: Predicts cloudbursts, waterlogging, and thermal shocks to prevent fertilizer washouts and crop destruction.
  • Direct Farmer-to-Consumer Market: Complete direct marketplace showing transparent price margins (0% middleman cut) with direct checkout.
  • Tri-Channel Accessibility: Seamless dissemination across modern smartphone web apps, 2G feature phones (cellular SMS), and automated regional IVR voice calls in English, Hindi, and Bengali.

Tech Stack:

React 19, TypeScript, Vite, Tailwind CSS v4, Recharts, FastAPI, Open-Meteo, Web Speech API.
